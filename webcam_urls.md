# Webcam URLs

This file contains all webcam URLs for the Mountain Weather website.
Edit this file to add, remove, or update webcam links without touching Python code.

## How to Comment Out URLs

You can temporarily disable webcams without deleting them by commenting them out:

**Method 1: Use # at the start of the line**
```
# - https://example.com/offline-webcam.jpg
```

**Method 2: Use HTML comments**
```
<!-- - https://example.com/offline-webcam.jpg -->
```

**Method 3: Add any text before the dash**
```
OFFLINE - https://example.com/offline-webcam.jpg
```
